## Strengths

- **Spoiler safety:** Hint payload uses fixed env/default copy; no `revealedWord`, no distance; `broadcastPlayerChatWithPerRecipientText` still runs for the real chat line.
- **Privacy:** `sendEvent(ws, …)` targets only the submitting socket; integration test asserts drawer receives zero `chatCloseGuessHint` events.
- **Protocol:** `chatCloseGuessHint` is in `serverEventSchema` with bounded `message`; `roomHydrate` clears `closeGuessHint` client-side and does not extend `hydrateChatTailWireSchema`.
- **Rate limiting:** Count + cooldown from `game.ts` resolvers; map cleared when leaving `drawing` / `returnToLobby`.
- **Client UX:** `MatchChatPanel` keeps hints out of `feed`; `motion-safe:animate-pulse` / `motion-reduce:animate-none`; exhaustive `default: never` in lobby WS handlers.
- **Observability:** `CLOSE_GUESS_HINT_LOG=1` logs `roomId`, `matchRoundIndex`, `playerId` only.
